
# GenAI Assignment 1 - Python Data Structures

## Problem Statement
A simple inventory utility for an e-commerce store.

## Task 1: Product Collections
Demonstrates Python lists and tuples.

## Task 2: Categories
Demonstrates Python sets and unique categories.

## Task 3: Product Pricing
Demonstrates dictionaries and basic price calculations.

## Task 4: Combined Operations
Combines lists, tuples and dictionaries to create a product catalog and group products by category.
