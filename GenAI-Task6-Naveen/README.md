
# Assignment 6: Exception Handling

## Task 1: Safe Division Utility
- Takes numerator and denominator from the user.
- Handles ValueError.
- Handles ZeroDivisionError.
- Uses else and finally blocks.

## Task 2: Bill Calculator with Error Handling
- Processes a list of product prices.
- Handles TypeError.
- Raises ValueError for negative prices.
- Calculates the running total.
- Skips invalid items.

## Task 3: Custom Exception - Age Validator
- Validates age between 1 and 120.
- Raises ValueError for invalid age.
- Handles the exception using try-except.

## Task 4: File Reader with Exception Handling
- Accepts a filename from the user.
- Reads the first three lines.
- Handles FileNotFoundError.
- Handles PermissionError.
- Uses finally block.

## Task 5: Mini Program - Safe Shopping Cart
- Accepts product prices from the user.
- Stops when the user enters q.
- Handles invalid inputs.
- Raises ValueError for negative prices.
- Displays total items and total bill.
